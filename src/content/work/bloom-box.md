VoiceType is a desktop application that converts speech to text in real-time using OpenAI's Whisper model. Built with Python and Electron, it provides a seamless dictation experience with automatic clipboard integration.

## Key Features

- **Real-time transcription** using OpenAI Whisper API for high-accuracy voice recognition
- **Automatic clipboard integration** — transcribed text is instantly copied and ready to paste
- **Hotkey activation** for quick start/stop recording without switching windows
- **Multi-language support** including Vietnamese and English
- **Minimal system tray UI** that stays out of your way

## Tech Stack

- **Backend**: Python, OpenAI Whisper API
- **Frontend**: Electron for cross-platform desktop support
- **Audio Processing**: Real-time audio capture and streaming
- **Distribution**: Packaged as standalone desktop app
