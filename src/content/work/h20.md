GHC Always Agent is an OpenCode plugin designed to maintain persistent GitHub Copilot Chat agent sessions. It ensures agents stay alive with automatic recovery, session management, and seamless integration into your development workflow.

## Key Features

- **Persistent agent sessions** that survive disconnections and editor restarts
- **Auto-recovery** with intelligent retry logic and exponential backoff
- **Session state management** to preserve conversation context
- **Configurable health checks** to monitor agent status
- **Minimal overhead** — runs silently in the background

## Tech Stack

- **Runtime**: TypeScript, Node.js
- **Integration**: OpenCode Plugin API, GitHub Copilot Chat
- **Architecture**: Event-driven with WebSocket connections
- **Distribution**: Published as OpenCode plugin
